# news_aggregator — 新闻聚合 & 公众号文章生成器

基于 [crawl4ai](https://github.com/unclecode/crawl4ai) 构建的新闻聚合模块，覆盖微博热搜、今日头条、新浪新闻、网易新闻、BBC 中文五大平台，聚合去重后通过 LLM 生成适合微信公众号发布的热点速览文章。

---

## 目录结构

```
news_aggregator/
├── __init__.py          # 对外暴露的公共 API
├── sites.py             # 各站点爬取配置（URL / CSS schema / 备用选择器）
├── crawler.py           # 爬虫核心：无头浏览器抓取 + 三级抽取兜底 + 指数退避重试
├── aggregator.py        # 去重（SequenceMatcher）+ 分类 + 跨源覆盖度排序
├── writer.py            # 文章生成：mock / Claude / OpenAI / DeepSeek 四种模式
├── main.py              # CLI 入口
├── requirements.txt     # 额外依赖（crawl4ai 本体在父目录）
└── output/              # --save 时文章保存位置（运行时自动创建）
```

---

## 新增 / 修改的代码

本模块为全新增，不修改 crawl4ai 主库任何文件。

| 文件 | 核心设计要点 |
|------|------------|
| `sites.py` | 每个站点含主 `schema`（JsonCssExtractionStrategy）和多套 `fallback_selectors`，抵御站点改版 |
| `crawler.py` | 三级抽取兜底：① 主 schema → ② 备用 CSS selector → ③ markdown 链接正则解析；指数退避重试（2 s、4 s、8 s） |
| `aggregator.py` | `SequenceMatcher` 相似度去重（含子串包含判断）；关键词多命中分类；按跨源覆盖数 + 热度数值双键排序 |
| `writer.py` | `LLMWriter` 统一接口，按 `mode` 分发到 mock 模板 / Anthropic / OpenAI / DeepSeek |
| `main.py` | `argparse` CLI，串联全流程（抓取 → 聚合 → 生成 → 可选保存） |

## 依赖安装

```bash
# 1. 安装 crawl4ai（从父目录源码安装，开发模式）
pip install -e ..

# 2. 安装 news_aggregator 额外依赖
pip install -r news_aggregator/requirements.txt

# 3. 首次运行需要下载 Playwright 浏览器内核（约 200 MB）
python -m playwright install chromium
```

> **Python 版本要求**：>= 3.10（使用了 `list[str]` 等 PEP 585 内置泛型）

## 开发模式（dev）

开发时使用 **mock 模式**，无需任何 LLM API Key，跑通全流程只需几分钟。

```bash
# 从项目根目录运行
cd /path/to/cc-crawl4ai

# 最简运行（mock，抓所有站点，输出到终端）
python -m news_aggregator.main

# 只抓指定站点（加快速度，方便调试单一站点）
python -m news_aggregator.main --sites 微博热搜 BBC中文

# 显示浏览器窗口（可视化调试 CSS selector）
python -m news_aggregator.main --no-headless

# 调整抓取量
python -m news_aggregator.main --max 10 --top 20   # 每站点最多 10 条，保留 20 条

# 保存到 output/ 目录查看 markdown 文件
python -m news_aggregator.main --save
```

### 调试 CSS selector

当某站点改版导致抓取为空时，按以下步骤排查：

1. 加 `--no-headless` 打开浏览器，手动检查页面结构
2. 在 `sites.py` 更新对应站点的 `schema.baseSelector` 和 `fields`
3. 将旧的选择器移入 `fallback_selectors`，保留向后兼容

## 生产模式（production）

生产环境选择一个 LLM 提供商，设置对应的环境变量即可。

### 使用 Claude（推荐）

```bash
export ANTHROPIC_API_KEY="sk-ant-..."

python -m news_aggregator.main --llm claude --save
```

### 使用 OpenAI（GPT-4o）

```bash
export OPENAI_API_KEY="sk-..."

python -m news_aggregator.main --llm openai --save
```

### 使用 DeepSeek（国内低成本替代）

```bash
export DEEPSEEK_API_KEY="sk-..."

python -m news_aggregator.main --llm deepseek --save
```

### 定时任务（cron）

每天早上 8 点自动生成并保存文章：

```cron
0 8 * * * cd /path/to/cc-crawl4ai && ANTHROPIC_API_KEY=sk-ant-... python -m news_aggregator.main --llm claude --save >> /var/log/news_aggregator.log 2>&1
```

## 完整参数说明

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--llm` | `mock` | LLM 模式：`mock` / `claude` / `openai` / `deepseek` |
| `--sites` | 全部 | 只抓指定站点名称，空格分隔，如 `微博热搜 BBC中文` |
| `--max` | `20` | 每个站点最多抓取的新闻条数 |
| `--top` | `40` | 去重 + 排序后保留的总条数 |
| `--no-headless` | 关 | 显示浏览器窗口，调试 selector 时开启 |
| `--save` | 关 | 将生成文章保存到 `news_aggregator/output/YYYYMMDD_HHMMSS.md` |

## 输出格式

文章以 **Markdown** 格式输出，结构如下：

```
# YYYY年MM月DD日 热点新闻速览

> 来源：微博热搜 / 今日头条 / 新浪新闻 / 网易新闻 / BBC中文

## 国际
1. [标题](链接) 🔥热度  _(来源)_
   > 摘要...

## 科技
...

---
_本文由 crawl4ai 自动聚合，仅供参考。_
```

LLM 模式下，文章由模型自由发挥，结构更接近真实公众号风格（导语 + 板块点评 + 总结），约 800–1200 字。

## 核心模块说明

### crawler.py — 三级抽取兜底

```
主 schema（JsonCssExtractionStrategy）
  └─ 为空 → fallback_selectors（逐一替换 baseSelector 重试）
              └─ 仍为空 → markdown 正则解析 [标题](url) 链接
```

- 每次网络/浏览器异常触发指数退避重试：等待 2 s、4 s、8 s
- 单站点失败不影响其他站点（`asyncio.gather(return_exceptions=True)`）
- 新闻是时效性内容，始终绕过 crawl4ai 缓存（`CacheMode.BYPASS`）

### aggregator.py — 去重与排序

- **去重**：`SequenceMatcher` 相似度 ≥ 0.7 视为重复，保留先出现的条目，并将被去重条目的来源记录到 `also_in` 字段
- **排序**：按 `coverage`（被几家来源报道）× `heat`（热度数值）双键降序排列
- **分类**：国际 / 科技 / 财经 / 社会 / 体育 / 娱乐 / 其他，按关键词命中数最多的类别归入

### writer.py — LLM 切换

`LLMWriter(mode="...")` 统一接口，内部按 mode 分发：

- `mock`：纯模板，无需网络，适合 CI / 离线测试
- `claude`：`anthropic` SDK，模型 `claude-sonnet-4-6`
- `openai`：`openai` SDK，模型 `gpt-4o`
- `deepseek`：复用 `openai` SDK（兼容 OpenAI 接口），模型 `deepseek-chat`

## 常见问题

**Q：某站点一直抓不到数据？**
A：用 `--no-headless` 打开浏览器确认页面能正常加载，然后在浏览器开发者工具中核对 `sites.py` 里的 CSS selector 是否仍然有效，更新后重跑。

**Q：想新增一个站点怎么做？**
A：在 `sites.py` 的 `SITES` 列表中追加一个 `SiteConfig`，填写 `url`、`schema`（baseSelector + fields）、`wait_for`，并酌情添加 `fallback_selectors`。

**Q：mock 模式下为什么有些分类是空的？**
A：mock 模式只走模板渲染，分类取决于爬取结果；如果某类别当天没有命中关键词的新闻，该分类就不会出现，属于正常现象。

**Q：LLM 模式费用大概多少？**
A：每次调用 prompt 约 1000 tokens，生成约 1200 tokens。以 Claude Sonnet 为例，单次费用约 $0.005，DeepSeek 更低约 $0.001。
