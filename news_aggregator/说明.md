# news_aggregator — 新闻聚合 & 公众号文章生成器

基于 [crawl4ai](https://github.com/unclecode/crawl4ai) 构建的新闻聚合模块，覆盖 **21 个国内外主流媒体**，聚合去重后通过 LLM 生成适合微信公众号发布的热点速览文章。

| 🎮 游戏 | IGN、Kotaku、Polygon |

## 目录结构

```
news_aggregator/
├── __init__.py          # 对外暴露的公共 API
├── sites.py             # 各站点爬取配置（URL / CSS schema / 备用选择器）
├── crawler.py           # 爬虫核心：无头浏览器抓取 + 三级抽取兜底 + 指数退避重试
├── aggregator.py        # 去重（SequenceMatcher）+ 分类 + 跨源覆盖度排序
├── writer.py            # 文章生成：mock / Claude / OpenAI / DeepSeek 四种模式
├── main.py              # CLI 入口
├── requirements.txt     # 额外依赖（crawl4ai 本体在父目录）
├── Dockerfile           # Docker 镜像（python:3.11-slim + Playwright + Chromium）
├── docker-compose.yml   # 服务编排：每小时自动爬取，挂载 output/ 目录
├── .env.example         # 环境变量模板
└── output/              # --save 时文章保存位置（gitignored，运行时自动创建）
```

## 核心设计

| 文件 | 核心设计要点 |
|------|------------|
| `sites.py` | 每个站点含主 `schema`（JsonCssExtractionStrategy）和多套 `fallback_selectors`，抵御站点改版；BBC 系列用 URL 模式锚定（`a[href*='/articles/']`），比 data-testid 容器更稳健 |
| `crawler.py` | 三级抽取兜底：① 主 schema → ② 备用 CSS selector → ③ markdown 链接正则解析；markdown 兜底含英文导航词过滤、图片链接过滤、最短标题长度校验（英文 ≥ 20 字符） |
| `aggregator.py` | `SequenceMatcher` 相似度去重；8 个分类：国际 / 科技 / 财经 / 社会 / 体育 / **科学** / 娱乐 / **游戏**；中英双语关键词；按跨源覆盖数 + 热度双键排序 |
| `writer.py` | `LLMWriter` 统一接口，按 `mode` 分发到 mock 模板 / Anthropic / OpenAI / DeepSeek |
| `main.py` | `argparse` CLI，串联全流程（抓取 → 聚合 → 生成 → 可选保存） |

## 依赖安装（本地开发）

```bash
# 1. 安装 crawl4ai（从父目录源码安装，开发模式）
pip install -e ..

# 2. 安装 news_aggregator 额外依赖
pip install -r news_aggregator/requirements.txt

# 3. 首次运行需要下载 Playwright 浏览器内核（约 200 MB）
python -m playwright install chromium
```

> **Python 版本要求**：>= 3.10

## Docker 部署（推荐生产使用）


## 核心模块说明

### crawler.py — 三级抽取兜底

```
主 schema（JsonCssExtractionStrategy）
  └─ 为空 → fallback_selectors（逐一替换 baseSelector 重试）
              └─ 仍为空 → markdown 正则解析 [标题](url) 链接
```

- 指数退避重试：等待 2 s、4 s、8 s
- 单站点失败不影响其他站点（`asyncio.gather(return_exceptions=True)`）
- 始终绕过 crawl4ai 缓存（`CacheMode.BYPASS`）
- markdown 兜底：预处理 `[![alt](imgurl)](link)` → `[alt](link)`，过滤图片 CDN 链接和导航词

### aggregator.py — 8 大分类（中英双语）

| 分类 | 代表关键词（中） | 代表关键词（英） |
|------|----------------|----------------|
| 国际 | 美国、北约、外交 | US, NATO, Reuters, AP News |
| 科技 | AI、芯片、华为 | OpenAI, Apple, TechCrunch |
| 财经 | 股市、美联储、比特币 | Fed, IPO, Bloomberg |
| 社会 | 事故、地震、疫情 | police, disaster, pandemic |
| 体育 | 世界杯、NBA、奥运 | NFL, Premier League, ESPN |
| 科学 | 研究、太空、NASA | scientists, discovery, Nature |
| 娱乐 | 电影、明星、票房 | Netflix, Oscar, Grammy |
| 游戏 | 电竞、主机、Steam | IGN, Kotaku, console |

### writer.py — LLM 切换

`LLMWriter(mode="...")` 统一接口：

- `mock`：纯模板，无需网络，适合 CI / 离线测试
- `claude`：`anthropic` SDK，模型 `claude-sonnet-4-6`
- `openai`：`openai` SDK，模型 `gpt-4o`
- `deepseek`：复用 `openai` SDK（兼容 OpenAI 接口），模型 `deepseek-chat`

## 常见问题

**Q：某站点一直抓不到数据？**
A：用 `--no-headless` 打开浏览器确认页面能正常加载，然后在开发者工具中核对 `sites.py` 里的 CSS selector 是否仍然有效，更新后重跑。

**Q：想新增一个站点怎么做？**
A：在 `sites.py` 的 `SITES` 列表中追加一个 `SiteConfig`，填写 `url`、`schema`（baseSelector + fields）、`wait_for`，并酌情添加 `fallback_selectors`。BBC 系列推荐用 `a[href*='/articles/']` 模式锚定，比依赖容器 class 名更稳健。

**Q：Bloomberg / FT 等付费墙站点能抓到数据吗？**
A：首页头条通常可见，但 Cloudflare 防护较强，主 schema 可能失败，会自动降级到 markdown 兜底抓取有限数量的标题链接。

**Q：Docker 镜像多大？**
A：约 2–3 GB（主要是 Chromium + Python 依赖），首次构建需下载 Playwright 浏览器内核。

**Q：LLM 模式费用大概多少？**
A：每次调用 prompt 约 1000 tokens，生成约 1200 tokens。Claude Sonnet 约 $0.005/次，DeepSeek 约 $0.001/次。
